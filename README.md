 ## 1. Project Overview
 - NexaNet Fraudshield AI is a machine learning model focused on financial fraud detection and risk assessment on transactions.
 - The platform aims to investigate logistic classification, anomally detection, and explainable AI techniques for identifying potentially fraudulent financial transactions.
 - The initial implementation focuses on developing Logistic Regression entirely from scratch using Numpy and Python.
 ### `NB` We are not going to use scikit learn models for our implementation we are going to create the machine learning algorithms from scratch by writing the python functions ourself.

 ## 2. Project Objectives
  - Develop a Logistic Regression classification model from scratch.
  - Investigate Financial transaction Fraud patterns.
  - Implement mathematical optimization using gradient descent.
  - Evaluate Model performance Under severe class Imbalance.
  - Investigate anomally detection usingisolation Forest.
  - Develop explainability capabilities.
  Prepare the ML engine for future REST API integration.
